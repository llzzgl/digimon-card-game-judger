## 🔍 验证方法

### 快速验证脚本

```python
from PIL import Image
import os

def validate_images(directory, file_extension):
    """验证指定目录下的图片"""
    results = []
    for f in sorted(os.listdir(directory)):
        if f.endswith(file_extension):
            filepath = os.path.join(directory, f)
            try:
                img = Image.open(filepath)
                results.append({
                    'filename': f,
                    'size_kb': round(os.path.getsize(filepath) / 1024, 1),
                    'resolution': f"{img.width}x{img.height}",
                    'status': '✅ OK',
                    'error': None
                })
                print(f"✅ {f}: {img.width}x{img.height} - OK")
            except Exception as e:
                results.append({
                    'filename': f,
                    'size_kb': round(os.path.getsize(filepath) / 1024, 1),
                    'resolution': 'N/A',
                    'status': '❌ FAILED',
                    'error': str(e)
                })
                print(f"❌ {f}: {e}")
    return results

# 验证日文图片
print("=== 日文图片验证 ===")
jp_dir = "D:/LLMProject/dtcg_judger/card_data/images/jp/raw"
jp_results = validate_images(jp_dir, '.png')

# 验证中文图片
print("\n=== 中文图片验证 ===")
cn_dir = "D:/LLMProject/dtcg_judger/card_data/images/cn/raw"
cn_results = validate_images(cn_dir, '.jpg')

# 汇总
print(f"\n=== 验证汇总 ===")
print(f"日文图片：{len([r for r in jp_results if r['status'] == '✅ OK'])}/{len(jp_results)} 通过")
print(f"中文图片：{len([r for r in cn_results if r['status'] == '✅ OK'])}/{len(cn_results)} 通过")
```

### 手动验证步骤

1. **文件完整性检查**:
   - 使用图片查看器打开每张图片
   - 确认无损坏、无错误提示

2. **内容匹配检查**:
   - 对照卡牌数据 JSON 文件
   - 确认图片内容与卡牌编号一致

3. **质量检查**:
   - 检查分辨率（建议≥800x1000）
   - 检查清晰度（无明显模糊或压缩痕迹）
   - 检查色彩（无明显色偏或失真）
