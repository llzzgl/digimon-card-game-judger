# 自动模型切换功能

## 功能说明

翻译工具现在支持自动模型切换，当遇到配额用尽错误时，会自动切换到下一个可用模型。

## 模型列表

按优先级排序：

1. **qwen-turbo** - 快速、便宜（优先使用）
2. **qwen-plus** - 平衡、高质量
3. **qwen-max** - 最高质量
4. **qwen-long** - 长文本处理

## 工作流程

```
开始翻译
    ↓
使用 qwen-turbo
    ↓
遇到配额用尽错误？
    ├─ 否 → 继续翻译
    └─ 是 → 切换到 qwen-plus
              ↓
         遇到配额用尽错误？
              ├─ 否 → 继续翻译
              └─ 是 → 切换到 qwen-max
                        ↓
                   遇到配额用尽错误？
                        ├─ 否 → 继续翻译
                        └─ 是 → 切换到 qwen-long
                                  ↓
                             遇到配额用尽错误？
                                  ├─ 否 → 继续翻译
                                  └─ 是 → 停止（所有模型用尽）
```

## 重试机制

### 单次API调用
- 每个模型最多重试3次
- 使用指数退避：1秒、2秒、4秒
- 遇到配额错误立即切换模型

### 整个QA翻译
- 每个QA最多重试3次
- 如果所有模型都用尽，返回原始数据并标记错误

## 使用示例

正常运行，无需特殊配置：

```bash
python translate_qa_with_terminology.py
```

输出示例：

```
[1/10] QA#5794 [问题] 调用Qwen API... 完成 [答案] 调用Qwen API... 完成 ✓
[2/10] QA#5795 [问题] 调用Qwen API... 配额用尽
  ⚠️ 模型 qwen-turbo 免费配额已用尽
  ⚠️ 切换到模型: qwen-plus
  ↻ 使用新模型重试...
  调用Qwen API... 完成 [答案] 调用Qwen API... 完成 ✓
```

## 配额管理建议

1. **监控使用量** - 在阿里云控制台查看配额使用情况
2. **升级付费** - 如果经常用尽配额，考虑升级到付费版本
3. **分批翻译** - 大批量翻译时分多次进行
4. **调整延迟** - 增加批次间延迟避免触发限流

## 自定义模型列表

如果需要调整模型优先级，编辑 `translate_qa_with_terminology.py` 第27行：

```python
self.qwen_models = [
    "qwen-turbo",      # 第一优先
    "qwen-plus",       # 第二优先
    "qwen-max",        # 第三优先
    "qwen-long",       # 第四优先
]
```

## 错误处理

### 配额用尽
- 自动切换到下一个模型
- 显示切换信息
- 继续翻译

### 网络错误
- 自动重试（最多3次）
- 使用指数退避
- 超时后报错

### 所有模型用尽
- 停止翻译
- 保存已翻译的内容
- 显示错误信息

## 检查点支持

即使遇到错误，已翻译的内容也会保存到检查点文件，下次运行时可以继续。
