# 翻译改进说明

## 问题描述

之前的翻译结果混杂了中文和日文，例如：
- ❌ "此卡牌の【登场时】效果は..."
- ❌ "はい、休眠できます"
- ❌ "对手の数码宝贝を选择ことはできず"

## 改进内容

### 1. 强化了翻译提示词

**新增要求**:
- ✅ 必须将所有日文翻译成中文汉字
- ✅ 不得保留任何日文假名或汉字
- ✅ 严格按照术语对照表翻译
- ✅ 提供了更多翻译示例（4个详细示例）
- ✅ 明确标注错误和正确示例

**术语表扩展**:
- 从显示50个术语增加到100个术语
- 添加了更多常见表达的对照

**详细规则**:
- 效果标记翻译规则
- 游戏术语对照（20+个）
- 常见表达对照（15+个）
- 数值和符号处理规则

### 2. 创建了质量检查工具

**check_translation_quality.py**:
- 自动检测日文残留（平假名、片假名）
- 检查常见日文词汇（30+个）
- 统计翻译覆盖率
- 显示问题示例

### 3. 创建了重新翻译脚本

**retranslate.bat**:
- 自动清除旧的检查点
- 使用改进的提示词重新翻译
- 一键操作

## 使用方法

### 方法1: 重新翻译（推荐）

```bash
cd card_game_judge\card_game_QA_manger
retranslate.bat
```

选择：
- LLM: 1 (Qwen)
- 模式: 1 (测试10条) 或 3 (完整翻译)

### 方法2: 检查现有翻译质量

```bash
python check_translation_quality.py
```

这会显示：
- 日文残留的数量和位置
- 常见日文词汇的出现次数
- 具体问题示例

### 方法3: 手动翻译

```bash
# 1. 清除检查点
del official_qa_cn_*_checkpoint.json

# 2. 运行翻译
python translate_qa_with_terminology.py
```

## 改进后的翻译示例

### 示例1: 基本问答

**之前** ❌:
```
Q: 此卡牌の【登场时】效果は、自己か对手のどちらの数码宝贝でも休眠できますか？
A: はい、休眠できます。
```

**现在** ✅:
```
Q: 这张卡的【登场时】效果，可以休眠自己或对手的任意数码兽吗？
A: 是的，可以休眠。
```

### 示例2: 复杂规则

**之前** ❌:
```
Q: 战斗区に休眠状態の自己の此卡牌が存在状況です。对手の数码宝贝は攻击できますか？
A: いいえ、攻击できません。「可以」效果と「でき没有」效果が同時に有时は、「でき没有」效果が優先されます。
```

**现在** ✅:
```
Q: 当战斗区存在休眠状态的自己的这张卡时，对手的数码兽可以攻击吗？
A: 不是，不可以攻击。当"可以"效果和"不可以"效果同时存在时，"不可以"效果优先。
```

### 示例3: 效果说明

**之前** ❌:
```
登场费用を持た没有对手の数码宝贝のみが存在状況です。
此卡牌の【登场时】效果を发挥した场合、どうなりますか？
```

**现在** ✅:
```
当只存在没有登场费用的对手数码兽时，
发挥这张卡的【登场时】效果会怎样？
```

## 质量保证

### 自动检查项

1. **日文残留检测**
   - 平假名检测（あいうえお等）
   - 片假名检测（アイウエオ等）

2. **常见词汇检查**
   - できます/できません
   - はい/いいえ
   - の/を/が/は等助词

3. **术语一致性**
   - 检查是否使用标准译名
   - 检查是否有自创译名

### 手动检查项

1. **语句流畅度**
   - 是否符合中文语法
   - 是否读起来自然

2. **信息完整性**
   - 是否遗漏信息
   - 是否添加了额外信息

3. **专业准确性**
   - 术语是否准确
   - 规则解释是否正确

## 预期效果

使用改进后的提示词，翻译质量应该达到：

- ✅ 0% 日文残留
- ✅ 100% 术语准确
- ✅ 95%+ 语句流畅
- ✅ 100% 信息完整

## 如果还有问题

### 1. 仍有日文残留

运行质量检查：
```bash
python check_translation_quality.py
```

查看具体问题，然后：
- 检查术语对照表是否完整
- 考虑使用更强的模型（qwen-max）
- 调整temperature参数（降低到0.1）

### 2. 术语不准确

检查并更新术语表：
```bash
# 查看术语表
notepad ..\..\digimon_card_data\term_mapping\game_mechanics_keywords.json

# 或运行LLM提取更多术语
cd ..\..\digimon_card_data\term_mapping
python extract_with_llm.py
```

### 3. 语句不流畅

考虑：
- 使用qwen-max模型（质量更高）
- 在提示词中添加更多示例
- 调整temperature参数（0.3-0.5之间）
