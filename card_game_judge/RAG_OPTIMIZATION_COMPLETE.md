## 🔧 详细修改内容

### 1. prompt_builder.py - 提示词构建器优化

#### 新增功能

**1.1 思维链（Chain of Thought）引导**
- 在系统角色中添加了完整的思维过程指导
- 包含 4 个步骤：识别关键元素 → 查找相关信息 → 分析互动关系 → 得出结论
- 每个步骤都有详细的子项说明

**1.2 不确定性表达指导**
- 明确说明如何处理不确定情况
- 提供置信度标注（高/中/低）
- 包含示例模板

**1.3 引用格式规范化**
- 规则引用格式：`根据综合规则 [章节号]：[规则内容摘要]`
- 卡牌引用格式：`[卡牌名称]（[卡牌编号]）的效果：[效果文本摘要]`
- 裁定引用格式：`根据官方 QA [编号/关键词]：[裁定内容]`

**1.4 多步骤推理指导**
- 回答模板标准化
- 特殊情况处理规则（规则冲突、语言差异）
- 信息来源优先级排序

#### 修改后的系统提示词结构

```markdown
- 系统角色（含思维链）
- 信息来源优先级
- 思维过程（4 步骤）
- 回答质量标准
- 相关规则
- 官方裁定
- 涉及卡牌
- 玩家问题
- 回答要求（含引用格式、不确定性处理、特殊情况）
```

### 2. search.py - 搜索引擎优化

#### 2.1 权重配置调整

**优化前**:
```python
SIMILARITY_WEIGHTS = {
    'semantic': 0.6,
    'keyword': 0.2,
    'importance': 0.1,
    'freshness': 0.1
}
```

**优化后**:
```python
SIMILARITY_WEIGHTS = {
    'semantic': 0.5,      # 降低语义权重
    'keyword': 0.3,       # 提高关键词权重（卡牌名称、规则术语）
    'exact_match': 0.2    # 新增精确匹配权重
}
```

#### 2.2 新增函数

**`extract_card_number(query: str) -> Optional[str]`**
- 从查询中提取卡牌号
- 支持多种格式：`BT5-086`, `BT5 086`, `BT5086`, `ST1-001`
- 返回标准化格式（如 `BT5-086`）

**`extract_rule_section(query: str) -> Optional[str]`**
- 从查询中提取规则章节号
- 支持格式：`规则 8.1`, `8.1 节`, `第 8.1 条`, `综合规则 8.1`

**`calculate_exact_match_score(...)`**
- 计算精确匹配分数
- 卡牌号精确匹配：+0.8 分
- 同系列卡牌：+0.3 分
- 规则章节精确匹配：+0.6 分
- 标题关键词匹配：+0.2 分

#### 2.3 重排序优化

**优先级规则**:
1. 卡牌号精确匹配 → 置顶（+0.5 bonus）
2. 规则章节精确匹配 → 次之（+0.3 bonus）
3. 语义相似度 → 再次
4. 已验证裁定 → 加成

### 3. chunker.py - 分块策略优化

#### 3.1 分块策略对比

| 文档类型 | 优化前 | 优化后 |
|----------|--------|--------|
| 规则 | 固定 512 tokens 递归分割 | **按章节分块** |
| 裁定/QA | 固定 512 tokens 递归分割 | **按 QA 条目分块** |
| 卡牌 | 固定 512 tokens 分割 | **整卡分块（不分割）** |

#### 3.2 规则分块（`_chunk_by_section`）

- 识别章节标题模式：
  - `第 X 章 XXX`
  - `8.1 XXX`
  - `Chapter X`
  - `Section X`
  - `一、XXX`
- 每个章节作为独立块
- 章节过长时递归分割

#### 3.3 裁定分块（`_chunk_qa`）

- 识别 QA 格式：
  - `Q: ... A: ...`
  - `问：... 答：...`
  - `【问题】...【回答】...`
  - `【Q】...【A】...`
- 每个 QA 对作为独立块
- 保持问答完整性

#### 3.4 卡牌分块（`_chunk_card`）

- **核心原则**: 保持卡牌完整性，不分割
- 只有超过 `chunk_size` 时才分割
- 按字段优先级分割（卡牌编号 > 名称 > 效果）
