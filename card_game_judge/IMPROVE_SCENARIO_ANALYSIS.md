# 改进场面分析能力指南

## 问题诊断

你的微调模型目前只返回卡牌数据，而不进行场面分析。原因是：

1. **训练数据缺失**：训练数据主要包含：
   - 规则书的问答（规则解释、关键词定义）
   - 卡牌数据的问答（卡牌信息查询）
   - 缺少**复杂场面分析**的示例

2. **提示词不够明确**：原有提示词没有明确引导模型进行逐步推理

## 解决方案

### 方案1：增加场面分析训练数据（推荐）

#### 步骤1：生成场面分析数据

```bash
cd card_game_judge/finetune
python add_scenario_analysis_data.py
```

这会生成包含5个场面分析示例的训练数据。

#### 步骤2：合并训练数据

```bash
# 重新收集所有数据，包括场面分析
python collect_all_data.py
```

然后手动将 `scenario_analysis_data.jsonl` 合并到 `dtcg_finetune_data.jsonl`：

```bash
# Windows
type training_data\scenario_analysis_data.jsonl >> training_data\dtcg_finetune_data.jsonl

# Linux/Mac
cat training_data/scenario_analysis_data.jsonl >> training_data/dtcg_finetune_data.jsonl
```

#### 步骤3：添加更多场面分析示例

编辑 `add_scenario_analysis_data.py`，添加更多真实的场面分析案例。建议添加：

- 你自己遇到的复杂场面
- 官方Q&A中的复杂裁定
- 社区讨论的经典案例

**示例格式**：

```python
scenario_n = {
    "question": """具体的游戏场面描述，包括：
    - 涉及的卡牌（卡号 + 卡名）
    - 当前的游戏状态
    - 发生的事件
    - 需要判断的问题""",
    
    "answer": """【涉及的卡牌效果】
    列出所有相关卡牌及其关键效果
    
    【相关规则】
    引用适用的规则条款
    
    【效果时机分析】
    分析各效果的触发时机
    
    【处理顺序】
    说明效果的处理顺序
    
    【场面推导】
    逐步推导场面变化
    
    【结论】
    给出明确的结论"""
}
```

#### 步骤4：重新训练模型

```bash
cd card_game_judge/finetune
python finetune_qwen.py --data training_data/dtcg_finetune_data.jsonl
```

## 训练数据质量建议

### 好的场面分析示例特征

✅ **结构清晰**
```
【涉及的卡牌效果】
【相关规则】
【处理顺序】
【结论】
```

✅ **逻辑完整**
- 从场面描述到结论，逻辑链完整
- 每一步都有依据（规则或卡牌效果）

✅ **真实场景**
- 基于实际游戏中会遇到的情况
- 包含多张卡牌的交互

✅ **明确结论**
- 给出明确的处理结果
- 如果有不确定性，明确说明

### 避免的问题

❌ **只列举卡牌效果**
```
BT23-032 土偶兽的效果是...
BT24-016 拉米亚兽的效果是...
```

❌ **缺少推理过程**
```
结论：会触发拉米亚兽的效果
（没有说明为什么、如何触发）
```

❌ **模糊不清**
```
可能会触发某些效果...
（没有明确说明是哪些效果）
```

## 数据量建议

- **最少**：20-30个场面分析示例
- **推荐**：50-100个场面分析示例
- **理想**：100+个场面分析示例

场面分析示例越多，模型的推理能力越强。

## 示例：你的问题

你的原始问题：
```
我方联展了bt23-032土偶兽，把对方的数码兽退化成bt24-016拉米亚兽，
并选择其主要阶段开始时攻击，土偶进化源中有bt23-027天使兽和
bt23-050甲龙兽。对方拉米亚进化源中有bt21-001基基兽。
此时移交回合后会发生什么？
```

理想的模型输出应该是：
```
【涉及的卡牌效果】
1. BT23-032 土偶兽：联展效果...
2. BT24-016 拉米亚兽：【主要阶段开始时】效果...
3. BT23-027 天使兽：进化源效果...
4. BT23-050 甲龙兽：进化源效果...
5. BT21-001 基基兽：进化源效果...

【相关规则】
• 规则 15-9：多个效果同时触发时的处理顺序
• 规则 6-1：回合流程

【处理顺序】
1. 移交回合，变为对手回合
2. 对手主要阶段开始时，所有【主要阶段开始时】效果同时触发
3. 按"回合玩家→非回合玩家"顺序处理：
   - 先处理对手的拉米亚兽和基基兽效果
   - 再处理我方土偶兽进化源的效果

【结论】
（具体结论取决于各卡牌的实际效果）
```
