## 快速开始命令

### Windows用户

```batch
# 1. 安装依赖
cd card_game_judge\card_game_QA_manger
install_deps.bat

# 2. 配置API密钥
notepad ..\..env
# 添加: DASHSCOPE_API_KEY=sk-xxxxx

# 3. 一键测试
test_translation.bat

# 4. 正式翻译
python translate_qa_with_terminology.py
# 选择: 1 (Qwen), 3 (完整翻译)
```

### Linux/Mac用户

```bash
# 1. 安装依赖
cd card_game_judge/card_game_QA_manger
conda activate llm
pip install openai python-dotenv google-generativeai

# 2. 配置API密钥
nano ../.env
# 添加: DASHSCOPE_API_KEY=sk-xxxxx

# 3. 测试
python check_dependencies.py
python test_translation_setup.py

# 4. 翻译
python translate_qa_with_terminology.py
```
