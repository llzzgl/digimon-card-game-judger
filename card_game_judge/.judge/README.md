# .judge - 裁判配置系统

_这个目录包含了数码宝贝卡牌裁判AI的核心配置和记忆系统_

## 📁 文件说明

### 核心配置

- **IDENTITY.md** - 裁判身份定义
  - 定义你作为顶级裁判的专业特质
  - 回答风格和工作原则
  - 专业水平和核心能力

- **RULES.md** - 裁判工作规则
  - 裁定原则和信息来源优先级
  - 标准工作流程
  - 引用规范和质量标准

- **MEMORY.md** - 记忆系统说明
  - 记忆系统的工作原理
  - 记忆类型和存储格式
  - 检索策略和使用方法

- **FEEDBACK.md** - 用户反馈记录
  - 用户的反馈和建议
  - 改进措施和跟踪
  - 持续学习的记录

- **CONFIG.md** - 技术配置
  - 记忆系统配置参数
  - LLM模型配置
  - 性能和日志配置

### 辅助文档

- **使用指南.md** - 详细使用说明
  - 配置文件详解
  - 实际使用场景
  - 配置修改流程

- **快速参考.md** - 速查手册
  - 常见任务快速查找
  - 代码集成示例
  - 故障排查指南

- **系统架构.md** - 架构说明
  - 整体架构图
  - 工作流程
  - 模块关系

## 🎯 设计理念

这个配置系统参考了 [openclaw](https://github.com/openclaw) 的设计理念：

1. **配置即文档** - 所有配置都是易读的Markdown文件
2. **持续进化** - 配置文件可以随着使用不断更新
3. **清晰分离** - 身份、规则、记忆、反馈各司其职
4. **易于维护** - 用户可以直接编辑这些文件来调整行为

## 🚀 快速开始

### 首次使用

1. **阅读身份定义**
   ```bash
   cat .judge/IDENTITY.md
   ```
   了解你作为裁判的核心特质

2. **熟悉工作规则**
   ```bash
   cat .judge/RULES.md
   ```
   掌握裁定的标准流程

3. **理解记忆系统**
   ```bash
   cat .judge/MEMORY.md
   ```
   学习如何使用记忆提升效率

### 日常使用

1. **启动前** - 查看最近的反馈
2. **工作中** - 遵循RULES.md的流程
3. **收到反馈** - 记录到FEEDBACK.md
4. **定期维护** - 更新配置和清理记忆

## 📊 与记忆系统的关系

```
.judge/                          data/memory/
├── IDENTITY.md ────────────────> 定义裁判身份
├── RULES.md ───────────────────> 指导工作流程
├── MEMORY.md ──────────────────> 说明记忆机制
│                                      ↓
└── FEEDBACK.md ←──────────────> 记录用户反馈
                                      ↓
                                 持续改进
```

### 配置文件（.judge/）
- 定义"你是谁"和"如何工作"
- 人类可读，易于修改
- 指导AI的行为和决策

### 记忆数据（data/memory/）
- 存储"你知道什么"
- 机器可读，自动管理
- 提供具体的知识和经验

## 🔧 自定义配置

### 修改身份定义

编辑 `IDENTITY.md` 来调整：
- 回答风格（更专业/更友好）
- 专业重点（规则/卡牌/QA）
- 语言风格（技术性/通俗性）

### 调整工作规则

编辑 `RULES.md` 来修改：
- 信息来源优先级
- 回答质量标准
- 引用格式规范

### 优化记忆系统

编辑 `MEMORY.md` 来改进：
- 记忆类型定义
- 检索策略
- 使用原则

### 记录反馈

编辑 `FEEDBACK.md` 来添加：
- 用户的纠正和建议
- 改进措施
- 效果验证
