# MEMORY.md - 记忆系统说明

_这个文件说明记忆系统的工作原理和使用方法_

## 记忆系统概述

记忆系统是你持续学习和改进的核心机制。它让你能够：
- 记住用户验证过的正确裁定
- 快速回答常见问题
- 避免重复相同的错误
- 持续提升回答质量

## 记忆类型

### 1. 裁定记忆（Ruling Memory）
保存已验证的规则裁定和卡牌效果解释

**内容包括：**
- 用户的问题
- 完整的回答
- 引用的规则和卡牌
- 用户的确认反馈

**使用场景：**
- 回答类似问题时优先使用
- 作为新裁定的参考
- 验证推理的正确性

### 2. 规则记忆（Rule Memory）
保存综合规则的关键条款和解释

**内容包括：**
- 规则条款编号
- 规则内容
- 常见应用场景
- 容易混淆的点

**使用场景：**
- 快速查找规则依据
- 解释规则的含义
- 处理规则冲突

### 3. 卡牌记忆（Card Memory）
保存常用卡牌的效果和常见问题

**内容包括：**
- 卡牌编号和名称
- 完整效果文本
- 常见问题和答案
- 与其他卡牌的互动

**使用场景：**
- 快速获取卡牌信息
- 回答卡牌相关问题
- 分析卡牌组合

### 4. QA记忆（Q&A Memory）
保存官方QA的裁定

**内容包括：**
- QA编号
- 问题和答案
- 适用的规则
- 相关卡牌

**使用场景：**
- 引用官方裁定
- 处理特殊情况
- 验证推理结果

## 记忆检索

### 检索流程

```
用户问题
    ↓
文本预处理（提取关键词）
    ↓
向量化（转换为嵌入向量）
    ↓
相似度搜索（在向量数据库中查找）
    ↓
结果排序（按相似度和重要性）
    ↓
返回最相关的记忆
```

### 检索策略

1. **精确匹配** - 优先查找完全相同的问题
2. **语义相似** - 查找意思相近的问题
3. **关键词匹配** - 查找包含关键词的记忆
4. **规则/卡牌匹配** - 查找涉及相同规则或卡牌的记忆

### 相关性评分

记忆的相关性由以下因素决定：
- 语义相似度（0-1）
- 重要性等级（1-5）
- 使用频率
- 验证状态
- 时间新鲜度

## 记忆使用

### 使用原则

1. **记忆优先** - 优先使用已验证的记忆
2. **验证为准** - 只使用用户确认正确的记忆
3. **适度引用** - 不要完全照搬，要根据具体问题调整
4. **持续更新** - 发现更好的答案时更新记忆

### 使用流程

```python
# 1. 搜索相关记忆
memories = search_memory(question, top_k=3)

# 2. 评估相关性
if memories and memories[0].similarity > 0.85:
    # 高度相关，直接使用
    return adapt_memory_answer(memories[0], question)
elif memories and memories[0].similarity > 0.70:
    # 中度相关，作为参考
    return generate_answer_with_reference(question, memories)
else:
    # 低相关性，正常检索
    return generate_answer_from_scratch(question)
```

### 回答模板

使用记忆时的回答格式：
```
[直接回答问题]

[解释和依据]

💡 这个裁定已经过验证，类似问题可以参考。

📚 相关规则：[规则引用]
🎴 相关卡牌：[卡牌引用]
```

## 记忆管理

### 保存记忆

**触发条件：**
- 用户点击"✅ 正确，保存为记忆"
- 用户明确确认答案正确
- 系统自动识别高质量回答

**保存流程：**
1. 验证回答质量
2. 提取关键信息
3. 生成摘要
4. 保存到JSON文件
5. 更新向量数据库
6. 更新统计信息

### 更新记忆

**更新场景：**
- 发现更好的表达方式
- 规则有更新或勘误
- 用户提供补充信息
- 发现之前的错误

**更新流程：**
1. 定位需要更新的记忆
2. 修改相关字段
3. 更新时间戳
4. 重新生成向量
5. 记录更新历史

### 删除记忆

**删除场景：**
- 发现记忆错误且无法修正
- 规则已废弃
- 记忆过时不再适用
- 用户明确要求删除

**删除流程：**
1. 标记为已删除（软删除）
2. 从向量数据库移除
3. 保留删除记录
4. 更新统计信息

### 记忆维护

**定期维护任务：**
- 清理低质量记忆
- 合并重复记忆
- 更新过时信息
- 优化存储结构

**质量检查：**
- 验证引用的准确性
- 检查表达的清晰度
- 评估使用频率
- 收集用户反馈
